# COMMISSION-ME_PROTOTYPE
My website where you can commission me. (Final Project for Cobol)

COBOL ACTIVITY: BUILD YOUR OWN ONLINE SHOP

Due Dec 12
It's time to put your programming knowledge and newly acquired GitHub skills into practice!

For this project, you will build your own online shopping web application inspired by any product or business you want.

You can create a:

    Clothing store
    Gadget shop
    Sneaker store
    Bookstore
    Grocery store
    Food shop
    Or Even Services (Contact Center, AI company, Tesla Inspired)
    (Surprise me)

You have the freedom to choose your products, design your store, and create your own shopping experience.

IMPORTANT: Your application MUST have three major components:

1. USER INTERFACE (UI)

    Create your own shopping interface.
    Display products, names, prices, and available quantities.
    Allow customers to select products and enter quantities.
    Display the order summary and total amount.
    Make your application presentable and user-friendly.

2. API INTEGRATION

    Your UI must communicate with your backend through an API.
    Product selections and order information must be passed to the backend.
    Display the results returned by your backend.

3. COBOL BACKEND

    COBOL must perform the actual business calculations.
    Calculate subtotals and total amounts.
    Process product quantities and orders.
    Apply appropriate conditions and validations.
    Return the calculated results to your application.

IMPORTANT: COBOL must genuinely handle the business logic. Simply including a COBOL source file in your repository without actually using it in your application will not satisfy the requirement.

DEVELOPMENT ENVIRONMENT

You are free to use:

    GitHub Codespaces
    GitHub Copilot or other AI coding assistants
    Online resources and documentation
    Your preferred development tools

You may use my provided project template or create your own GitHub repository from scratch.

You are encouraged to experiment, be creative, and use AI-assisted development.

However, you must understand the code you submit and be prepared to explain how your UI, API, and COBOL backend work together.

SUBMISSION REQUIREMENTS

You will ONLY submit the following:

1. GITHUB REPOSITORY LINK

    Your repository must be PUBLIC.
    Make sure all project files and source codes are accessible.
    I must be able to inspect your implementation.

2. MICROSOFT LEARN BADGE LINK

    Submit the link to your completed "Code with GitHub Codespaces" training achievement.
    Make sure your badge or achievement is accessible.
